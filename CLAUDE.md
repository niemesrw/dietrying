# Claude Code Instructions

## Project Overview

This is **dietrying** - a collaborative project exploring how AI is changing things.

**Important**: This is primarily a discussion and documentation project, not a code project. The team uses Slack for discussion and AI agents to capture ideas to this repo.

## Workflow

The team's workflow is agent-driven:
1. Discussions happen in `#dietrying` on Slack
2. `@github` (Copilot) in Slack captures ideas to this repo
3. Notifications flow back to Slack when the repo updates

See [README.md](README.md) for the visual workflow diagram.

## Repository Structure

```
ideas/     - Rough thoughts, brainstorms, early-stage exploration
docs/      - More polished or structured documents
```

## Guidelines for Claude

When working in this repo:

1. **Keep it simple** - This is for non-technical collaborators. Avoid unnecessary complexity.
2. **Markdown only** - All content should be plain markdown files.
3. **Preserve the workflow** - Don't introduce tools or processes that require git knowledge.
4. **Respect the structure** - New ideas go in `ideas/`, polished content goes in `docs/`.
5. **Be accessible** - Write for a general audience, not developers.
